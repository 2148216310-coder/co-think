# co-think · 一起思考

让 AI 像人一样，和你轮流思考——先问清楚、让你先想，再综合分析。

## 解决的问题

人和人交流是轮流、双方同时思考的；人和 AI 交流却常常是「你给条件 → AI 立刻总结结论」，人的思考过程消失了。而且一轮往往讲不清关键信息，AI 却一开始就急着整合分析。

`co-think` 是一个 Codex skill，它改变 AI 的对话节奏：不再第一轮就甩结论，而是引导式地逐轮澄清、请你先说出自己的推理，直到你确认「汇总点」后再综合分析。

## 安装

克隆到 Codex 技能目录：

```bash
git clone https://github.com/2148216310-coder/co-think.git ~/.codex/skills/co-think
```

或手动把 `SKILL.md` 和 `agents/openai.yaml` 复制到 `~/.codex/skills/co-think/`。

> 也兼容跨运行时的 `~/.agents/skills/co-think/`（Codex / Copilot CLI / Gemini 通用）。

## 使用

新会话中，以下场景会自动触发：

- 帮我分析 / 一起想 / 怎么决定 / 该不该 / 方案 / 权衡 / 规划

也可以显式唤起：

```text
$co-think
```

## 它怎么做（对话协议）

1. 先说明进入「轮流思考」，问**一个**聚焦问题。
2. 请你先说出自己的想法、理由、倾向。
3. 复述确认你的意思。
4. 累积「已知信息」清单。
5. 信息足够时提出汇总点，你确认后才综合分析。

综合输出固定四段：结论 → 关键推理 → 仍存的假设 / 未知 → 建议下一步。

## 为什么不是「问更多」

它不追求把问题问得越多越好，而是：每轮只问一个、先让你想、再复述确认，最后给出可追溯的结论。
